How it works

  1. Snapshot — cursor-paginated GraphQL pull of the space (both Geo API dialects).
  2. Score — two-tier URL identity (report URLs vs profile links), name normalization, relation-shape conflicts; transitive clustering only over ≥0.9 edges.
  3. Fix plan — deleteEntity / replaceRelation ops with advisory skips; governance-proposal entities are always protected.
  4. Publish — GRC2 binary edit (codec 0.4.x) → IPFS → SpaceRegistry proposal from your Geo smart account; editors vote, the merge applies.
