# Geo Curator Copilot

Dedup-движок + CLI + MCP-сервер для кураторов Geo (geobrowser.io, GRC-20).
pnpm-монорепа, TS strict: packages/core (движок), client (GraphQL/publish),
cli (geo-copilot), mcp-server. Тесты: `./node_modules/.bin/vitest run` (34).

Первым делом прочитай CONTEXT.md — это полный handoff из исходного чата:
миссия, стратегия (5 шагов), все добытые константы, закрытые грабли, статус.

Если пользователь просит «выполни пилот / опубликуй дедуп / продолжай миссию»
— следуй RUNBOOK.md
в корне репозитория. Главные правила оттуда: ключ только из env GEO_PRIVATE_KEY
(никогда не печатать), всегда dry-run перед публикацией, боевой запуск только
после явного подтверждения пользователя.
